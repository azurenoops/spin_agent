# CSP home and impact — interactive IA mock

Proposed overlay on the Feature 079 provider workspace. **Not** a required UI
target until Feature 079 (or a follow-on) absorbs it. Does not replace
[provider-workspace-mock](../provider-workspace-mock/index.html).

Open [index.html](index.html). Synthetic records only. No Azure, Entra, eMASS,
or production APIs. Simulation state lives in memory and resets on reload.

Walk:

1. Overview → Offerings → Secure Enclave → **CRM**. Assign SA-9 (starts unassigned). Publish is blocked until every control is inherited / shared / customer. Publish CRM (missions do not auto-move).
2. **Inheritance** → Publish r3. Existing adopters become drifted; they are not upgraded.
3. **Subscribers** → 551st ISRW request → **Run what-if**.
4. What-if: Request → Declare use (try IL4 vs IL5 vs extra path) → Estimate → Refuse or Approve. Invalidating approve still does not expand the parent ATO.
5. Home queue / Tenant impact still work. Design bar: Empty / Unavailable / Restricted.

Restricted hides invalidating detail from an assessor preview. Empty is a
tenant with no attached MOs. Unavailable is an impact-service failure, not
“no risk.”
